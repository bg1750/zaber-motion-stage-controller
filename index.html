Zaber Motion Stage Controller

A desktop control panel for linear and rotary motion stages. Python and tkinter.

This is a simulated stand-in for professional work I can't share publicly. It reuses the same control panel and the same hardware-abstraction approach, wired to a simulator instead of the real stages.

What it does

  • One card per axis with Home, Jog, Go to, and an optional speed.
  • Live position readout and a MOVING, IDLE, OFFLINE, or ERROR status pill per axis.
  • Linear axes in mm and rotary in degrees, each with its own travel range and max speed.
  • Out of range moves are refused with a clear message.
  • STOP ALL (also on the Esc key) and a per axis stop.
  • A built-in simulator, so it runs with no hardware attached.

Run it

This is a desktop app, so it runs locally rather than in the browser:

python stage_console.py
