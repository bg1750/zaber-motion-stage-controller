# Changelog

## v1.0
- Initial release.
- One control card per axis: Home, Jog, Go-to, speed, and live position readout.
- MOVING / IDLE / OFFLINE / ERROR status pills.
- Linear (mm) and rotary (deg) axes with per-axis travel range and max speed.
- Range checking on moves, STOP ALL (Esc), and per-axis stop.
- Built-in simulator so the panel runs with no hardware attached.
